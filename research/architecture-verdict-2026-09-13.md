# 架构收敛：已定的、我反对的、先做哪三件

> 日期：2026-09-13
> 输入：外部评审（Codex）给出的四者架构与 10 步开发顺序；本文是对它的收敛意见。

---

## 一、已定，不再讨论

**一句话**：管家负责陪伴与交流，控制台负责观察与管理，阿罗德斯负责思考与负责，DSH 负责执行复杂任务。

| 名称 | 核心职责 |
|---|---|
| **管家** | 形象、语音、提示、状态表达、直接交互。要"薄" |
| **控制台** | 屏幕观察、活动采集、配置、日志、权限、诊断 |
| **阿罗德斯** | 产品中枢：理解目标、选择下一步、管理记忆、调度执行、验证结果 |
| **DSH** | 可替换的通用执行引擎。**不接管主循环** |

核心决定：**不把项目改造成 DSH 插件**；阿罗德斯当中枢，DSH 放在自定义执行器接口之后。

---

## 二、我同意，且它顺手解决了两个悬空问题

1. **它绕过了我评审简报里的第 2 问。**
   我原来的假设是"把自己的 30 秒主循环作为调度插件塞进 DSH"，并明确标注**未实证**。Codex 的方案**不需要这个假设**——DSH 在接口之后，不接管循环。
   → 那条"make-or-break 的悬空假设"作废，整条路线的风险下降一档。

2. **目录名保留、不当产品概念。** 解决了上一轮"`Agent/`、`Butler/` 要不要重命名"的问题——不重命名，只是以后不再拿它们当产品词。

三条对应到具体病灶，直接可用：
- 权限按"意图"管理 → 治「卸载软件删不干净」的病（现黑名单正是病因）
- 独立更新守护程序 + 验证器分工 → 治 `self_modify` 的危险（`danger-full-access` + 无回滚 + 无验证）
- 卸载验证清单 → 治"能判断命令退出，不能判断目标完成"

## 三、我不同意的两点

### 1. 顺序会让它死在第一步

Codex 把「固化四者协议」放第 1 步，「接入 DSH 实验」放第 7 步。
**协议设计是无底洞**，你会在那儿停住，而且停住的时候手上没有任何可跑的东西。

而它自己已经把 `ExecutionRequest` / `ExecutionResult` 写出来了 —— **那就是最小协议，够用了。**
→ 建议把第 1 步和第 7 步合并：**定义最小协议，然后立刻拿它跑真事。**

### 2. 体量超出你的承受范围（这条更要紧）

10 步 + 8 项缺失能力 + 一个新守护程序 + 统一事件协议 + 任务状态机 = 几个月的工程量。

而你同期还有：挑战杯、数模国赛、六级（12-19 前推过）。

**照这份完整跑，结果不是完成，是又一次停在半路。** 必须先砍——砍到"两周内能看到第一个端到端闭环"。

## 四、砍版：三步

筛选标准：**不管换不换 DSH 都要做，且立刻有收益。**

### 第 1 步 · 可立即开始，不依赖 DSH

**做**：定义执行器接口 + 权限意图化 + `self_modify` 加安全网

- 落地 `ExecutionRequest` / `ExecutionResult`（直接用 Codex 给的结构）
- 权限从"命令字符串黑名单"改为"意图描述"：
  `允许卸载指定软件` / `允许删除其程序目录` / `禁止删除用户文档` / `操作完成后必须验证`
- `self_modify`：每步 git 提交 + 一条命令回滚 + 改完跑 smoke test

**验收**：用一个本地的「本地技能执行器」实现，跑通一次请求 → 结果的完整往返。

### 第 2 步 · 端到端修好「卸载软件」

这是你自己举的例子，也是最好的第一块试金石：需求明确、可验证、痛点真实。

**验收清单**（照抄 Codex）：
- 主程序是否消失
- 进程是否退出
- 服务和计划任务是否删除
- 开机启动是否清除
- 残留文件是否需要保留
- 是否需要重启
- 用户要求保留的数据是否还在

**关键点**：验证的是"**目标是否完成**"，不是"命令是否退出"。

### 第 3 步 · 把 DSH 接到第 1 步的接口后面

跑一个隔离任务，做契约测试。

**验收**：
- 任务执行 / 取消 / 权限 / 结果结构四项契约测试通过
- DSH 不可用时，阿罗德斯的基础闭环不受影响

## 五、暂时不做（写下来，免得手痒）

统一事件协议、任务状态机持久化、事件日志、独立更新守护程序、`Agent`/`Butler` 合并、第三方插件接入。

**这些都是对的，但不是现在。** 等第 2 步跑通、你确认自己还在这个项目上，再按 Codex 的 3 → 10 顺序补。

Codex 那份是**正确的路线图**；你要的是**能活到路线图中段的版本**。

# 04 · 技能与工具

## 注册机制（skills/registry.ts）

```ts
registerSkill({
  name: 'skill_name',        // LLM 看到的工具名
  description: '...',        // 触发说明
  parameters: {...},         // JSON Schema
  execute: async (params) => result,  // 实现
})
```

- `getAllSkills()` / `executeToolCall(name, params)` / `unregisterSkill()`
- 技能描述拼进 Agent 系统提示（buildSkillsPrompt），LLM 按需调用
- devworkflow 技能族：由 **Agent 路由** 直接分发（见 [[05-Agent系统]]）

## 技能全量清单

### 内置工具（skills/builtin.ts）
| 技能 | 说明 |
|------|------|
| get_time | 报时 |
| web_search / web_fetch | 联网搜索/抓取 |
| read_file / write_file / overwrite / list_dir / index | 文件操作 |
| search_memory / memory_list_all / memory_stats / memory_cleanup / delete_memory | 记忆管理 |
| exec_command | 执行命令（需确认） |
| system_info | 系统信息 |
| content / query / source / target / topic / title / ticket / city / lines / path / url / voice / command / create_session / delayMinutes / code-review / grill-me / implement / improve-architecture / to-spec / to-tickets | devworkflow 族参数/指令 |

### 提醒（skills/reminder.ts）
| 技能 | 说明 |
|------|------|
| set_reminder | 设置提醒（相对/绝对时间），联动 mainloop 到期推送 |
| list_reminders / cancel_reminder | 列出/取消 |

### 天气（skills/weather.ts）— 阶段 2 新增
| 技能 | 说明 |
|------|------|
| get_weather | Open-Meteo 免费 API（免 key）；20+ 中国城市内置坐标 + geocoding 兜底；WMO 天气码中文本地化；网络失败友好兜底 |

### 显式指令（不走技能系统，WS handler 拦截）
- `记住X` / `忘了X` → services/explicitMemory.ts（见 [[03-记忆系统]]）

## 与 Agent 的关系

- main Agent：完整技能列表（buildSkillsPrompt）
- dev Agent：devworkflow 技能族（grill-me / to-spec / to-tickets / implement / code-review / improve-architecture）+ 技能 Agent Loop（≤3 轮）
- memory Agent：记忆提取专用

# 01 · 架构与模块

## 总体架构

```
┌─────────────────────────────────────────────────┐
│  Electron 桌面壳 (desktop/)                       │
│   fork 后端子进程 + 加载 http://localhost:3002    │
└────────────────────┬────────────────────────────┘
                     │
┌────────────────────▼────────────────────────────┐
│  Server (server/ · Node + TS · 端口 3002)        │
│  ├── REST 路由 /api/v1/*                         │
│  ├── WebSocket /v1/chat（WS + requestId 协议）    │
│  ├── Harness 编排（Agent 路由）                   │
│  ├── MemoryGateway（记忆提取/召回/整理）           │
│  ├── Mainloop（30s tick 主循环）                  │
│  └── 静态托管 client/dist                        │
└──────┬───────────────────────────┬──────────────┘
       │ HTTP                       │ HTTP (懒启动)
┌──────▼──────────┐        ┌────────▼─────────────┐
│ Client (React)  │        │ TTS Sidecar (Python) │
│ 语音/聊天/面板   │        │ CosyVoice2 · 12001   │
└─────────────────┘        └──────────────────────┘
```

## Server 核心模块

| 模块 | 路径 | 职责 |
|------|------|------|
| 入口 | `src/index.ts` | Express + WS + 静态托管 + 启动 mainloop |
| WS 处理 | `src/ws/handler.ts` | 消息接收 → 显式指令拦截 → Agent 路由 → 流式返回 |
| 编排 | `src/harness/harness.ts` | Agent 注册 / 路由（route）/ 执行 |
| Agent | `src/harness/agents/` | main（对话）/ memory（记忆）/ dev（开发） |
| 记忆 | `src/services/MemoryGateway.ts` | 提取/召回排序/人物识别/去重合并 |
| 主循环 | `src/services/mainloop.ts` | 30s tick：提醒 + 记忆整理 + 状态 |
| LLM | `src/services/llmService.ts` | 流式调用 + prompt 外壳合并 |
| 模型 | `src/services/modelRegistry.ts` | 6 内置模型 + 自定义 Provider 持久化 |
| 语音代理 | `src/services/cosyVoiceProxy.ts` | 侧车懒启动/健康检查/合成转发 |
| 外壳提示 | `src/services/promptShell.ts` | 可精炼外壳（版本化 + 回滚） |
| 技能 | `src/skills/` | registry + builtin + reminder + weather + devworkflow |

## Client 核心模块

| 模块 | 路径 | 职责 |
|------|------|------|
| 语音 | `src/voice/hooks/useTTS.ts` | 合成/播放/音色回退/音频可视化 |
| 状态球 | `src/components/AgentStatusOrb.tsx` | 聆听蓝/思考金/说话青/连接紫 光晕 |
| 记忆面板 | `src/components/MemoryPanel.tsx` | 记忆列表 + 人物卡 + 搜索/过滤 |
| 模型设置 | `src/components/ModelSettings.tsx` | 模型切换 + 自定义 Provider 表单 |

## TTS Sidecar（Python）

- 单文件 `tts_sidecar.py`（FastAPI），懒加载 CosyVoice2-0.5B 模型
- 环境变量 `COSYVOICE_PROJECT_DIR` 可指向本机模型项目（桌面打包版依赖此机制）
- 模型路径：`CosyVoice-unzip/cosyvoice-main/pretrained_models/CosyVoice2-0.5B`

## 桌宠 TheFool（Python · PyQt6）

- `desktop_pet.py`：透明窗口 + 立体投影光晕 + 气泡（多行自动换行，限宽 320px）
- HTTP 轮询后端任务/结果，实时播报
- 打包：PyInstaller → `dist*/桌宠-愚者.exe`（需 `--distpath` 独立目录避开沙箱）

## Desktop 壳（Electron）

- `desktop/main.ts`：fork 后端子进程（`resources/server/dist/index.js`）+ 加载前端
- `extraResources` 打包：server / client/dist / **tts-sidecar 脚本**
- 模型不入包（5.3GB），运行时经 `COSYVOICE_PROJECT_DIR` 指向本机

## 数据流：一次语音对话

```
麦克风 → STT → WS message {content, requestId}
  → handler: 显式指令?(记住X/忘了X → 直接读写记忆库，秒回)
  → harness.route(content) → main | memory | dev
  → Agent 流式回复 → chunk 推回前端
  → 前端 TTS: POST /api/v1/tts/synthesize → server → sidecar → audioBase64 → 播放
  → 对话后: memory Agent 后台提取记忆 → MemoryGateway
```

## 一、项目定位

**阿罗德斯** 是一个以"一面能看见你的镜子"为终极形态的多模态 AI 智能体系统。核心差异化：
- 语音优先交互（STT + TTS 闭环）
- 长时记忆系统（Hermes + 本地共享记忆）
- 会话即星球（3D 宇宙可视化）
- 沉浸式字幕体验（透明字幕 + 双音色 TTS）
- 多模态视觉理解（摄像头 + Qwen3-VL）
- 星球生长特效（光束 + 冲击波 + 粒子凝聚）
- 引力轨道系统（椭圆 + 倾斜 + 脉冲）

## 四、Qwen3-VL 视觉服务

### 模型信息

| 项目 | 内容 |
|------|------|
| 模型名 | `qwen3-vl:4b-instruct` (已下载)         |
| 模型大小 | ~3.3GB |
| 运行环境 | Ollama (已安装) |
| 显存要求 | 约 4-5GB (RTX 4060 可跑) |

### API 端点

| 端点 | 方法 | 说明 |
|------|------|------|
| `/api/v1/vision/status` | GET | 检查模型状态 |
| `/api/v1/vision/analyze` | POST | 上传图片分析 (multipart) |
| `/api/v1/vision/analyze-base64` | POST | Base64 图片分析 (JSON) |

### 接入方式
前端支持：拍照（摄像头） / 上传文件 → Base64 → Qwen3-VL 描述

> 版本：v3.0

## 一、项目定位

**阿罗德斯** 是一个以“一面能看见你的镜子”为终极形态的多模态 AI 智能体系统。

### 核心差异化

| 能力             | 说明                                 |
| ---------------- | ------------------------------------ |
| **语音优先交互** | STT + TTS 闭环，纯本地或云端可选     |
| **长时记忆系统** | Hermes + 本地共享记忆，多 Agent 共享 |
| **会话即星球**   | 3D 宇宙可视化，记忆的视觉隐喻        |
| **沉浸式字幕**   | 透明悬浮字幕 + 双音色 TTS            |
| **多模态视觉**   | Qwen3-VL 本地部署，摄像头理解        |
| **可扩展架构**   | 模块化 + 工作流 + 插件化             |

## 三、核心模块详解

### 3.1 透明字幕系统 (Subtitle System)

| 属性     | 默认值         | 可配置       |
| -------- | -------------- | ------------ |
| 文字颜色 | 白色 (#FFFFFF) | ✅            |
| 文字描边 | 黑色半透明     | ✅            |
| 字体大小 | 24px           | ✅ (小/中/大) |
| 字幕位置 | 底部居中       | ✅            |
| 背景     | 完全透明       | ❌            |
| 显示方式 | 打字机逐字     | ✅            |
| 停留时间 | 2秒后淡出      | ✅            |

**交互状态**：

| 阿罗德斯状态 | 字幕行为               |
| ------------ | ---------------------- |
| 用户说话     | 字幕隐藏               |
| AI 思考中    | 显示 "…"               |
| AI 回复中    | 逐字显示，当前字符高亮 |
| AI 回复完成  | 完整显示 2 秒后淡出    |

### 3.2 TTS 双引擎设计

```
TTS 引擎层
├── TTS 管理器
│   ├── 引擎选择 (Edge / ChatTTS / Qwen / Fish)
│   ├── 音色切换 (男声管家 / 女声纯欲)
│   └── 语速/音调/音量控制
├── Edge TTS (云端/免费/快速) ← 默认
├── ChatTTS (本地/音色抽卡) ← 可选
└── Qwen TTS / Fish Speech (本地/高质量) ← 可选
```

**音色配置**：

| 角色      | 风格               | Edge TTS 音色        | 场景           |
| --------- | ------------------ | -------------------- | -------------- |
| 男声·管家 | 沉稳、可靠、神秘   | zh-CN-YunyangNeural  | 日常对话、指令 |
| 男声·神秘 | 富有磁性、讲故事感 | zh-CN-YunjianNeural  | 故事、科普     |
| 女声·轻柔 | 温暖、自然、亲切   | zh-CN-XiaoxiaoNeural | 情感交流       |
| 女声·可爱 | 活泼、俏皮         | zh-CN-XiaoyiNeural   | 轻松互动       |
| 女声·纯欲 | 温柔、轻声、抚慰   | zh-CN-XiaorouNeural  | 放松、睡前     |

### 3.3 视觉模块 (Qwen3-VL)

| 项目     | 信息                         |
| -------- | ---------------------------- |
| 模型     | Qwen3-VL 4B-instruct         |
| 部署方式 | Ollama 本地                  |
| 显存占用 | ~3.2 GB                      |
| 硬件     | RTX 3060 12GB (100% GPU)     |
| 功能     | 图像理解、视觉问答、场景识别 |
| 当前状态 | ✅ 已下载，可运行             |

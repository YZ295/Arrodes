### B. HoloJarvis —— 语音交互专家（重点新学）

| 借鉴点 | 说明 | 可迁移性 | 迁移到 Arrodes 的具体做法 |
|--------|------|---------|--------------------------|
| **拼音模糊唤醒** | 喊"贾维斯"，识别成"家维斯"也命中 + 噪音幻听过滤 | ✅ 高 | Arrodes 录音停止 → STT 文本做**同音归一化匹配**（如"阿罗德斯"命中"阿罗的丝"），降低误唤醒 |
| **语音优先交互状态机** | VAD 分句 → ASR → 唤醒判断 → 大脑 → 工具循环 → TTS → 桌宠联动 | ✅ 高 | Arrodes 现有 pipeline 可参考其**状态机清晰分层**（当前是 hook 回调链） |
| **克隆音 + 自动回退** | GPT-SoVITS 克隆音，服务没开自动回退系统音 | ✅ 高（已部分实现） | Arrodes 自定义音色已做（CosyVoice zero-shot），补**失败自动回退默认音色** |
| **全息桌宠 HUD 联动** | 反应堆随状态变色、对话字幕、系统遥测 | ✅ 中 | Arrodes 已有 AgentStatusOrb + 桌宠轮询，可补**状态色联动**（聆听蓝/思考金/说话青） |
| **17 内置工具** | 开应用/天气/音乐/截屏/读屏/发微信/倒计时/文件 | ✅ 中 | Arrodes skills 有 6 个，**补倒计时/报时/天气**（高频刚需） |
| **MCP 扩展** | 配置文件即插即用 | ✅ 中 | Arrodes 无 MCP；WorkBuddy 生态有，可规划 |
| **本地隐私** | 识别/记忆/桌宠全本地 | ✅ 已对齐 | Arrodes 本地 STT+TTS 已对齐 |
| **"记住…"显式记忆指令** | 说"记住…"跨重启持久化 | ✅ 高 | Arrodes 记忆靠 LLM 自动提取，**补显式记忆指令**（用户说"记住X"→ 直接写记忆库） |

### C. Prime Agent —— 架构与工程纪律（重点新学）

| 借鉴点 | 说明 | 可迁移性 | 迁移到 Arrodes 的具体做法 |
|--------|------|---------|--------------------------|
| **不可变核心 + 可精炼外壳** | 基础系统提示不可重写；/refine 只更新补充状态且可回滚 | ✅ 高 | Arrodes harness 的 Agent prompt 分层：**系统提示只读**，用户画像/记忆/技能描述为可演进外壳（已有雏形，补"版本化+回滚"） |
| **单工具模型** | 模型只有一个内置工具（IPython），一切走代码 | ✅ 中 | Arrodes 技能系统可借鉴：**收敛工具面**（模型少选工具，认知负担低）——不照搬 IPython，但可做"主工具 + 子调用" |
| **递归子代理一等公民** | rlm() 生成并行子代理，agent 编排 agent | ⚠️ 中 | Arrodes harness 已有 main/memory 多 Agent，**补子代理返回可编程处理**（复杂任务分解） |
| **daemon 长任务 + 重挂载** | 终端断开任务继续跑，可 reattach | ⚠️ 中 | Arrodes 是长驻服务已具雏形，**补任务状态持久化**（重启后未完成任务续跑） |
| **可执行技能（Python 包）** | 技能是可导入的包，能自我创建 | ⚠️ 低-中 | 远期：Arrodes 技能从"注册函数"升级"可导入模块" |
| **CI 分片 + 严格发布** | kernel-heavy 测试独立 job；补丁只修 bug | ✅ 高 | Arrodes 已有 41+ 测试，**补 CI 工作流 + 发布纪律**（版本化 dist） |
| **自愈机制** | daemon 版本不匹配自动恢复 | ⚠️ 中 | 远期：Arrodes 后端可做"崩溃自动重启" |

## 四、架构设计原则（重写后）

```
┌───────────────────────────────────────────────┐
│ client（React）：语音优先 + 光束视觉 + 人物卡      │
│  NeonInputBar / Subtitle / Sidebar / MemoryPanel │
└───────────────┬───────────────────────────────┘
                │ REST + WS（requestId 强类型）
┌───────────────▼───────────────────────────────┐
│ server（TS + Express + SQLite）                 │
│  mainloop（心跳/记忆整理/提醒）                    │
│  harness（main/memory 多 Agent，可精炼外壳）       │
│  MemoryGateway（提取/检索排序/去重/人物/显式指令）   │
│  skills（6 个 + 新增报时/倒计时/天气）              │
│  ttsService（本地 CosyVoice + 回退 + 自定义音色）   │
└───────────────┬───────────────────────────────┘
                │ HTTP
┌───────────────▼───────────────────────────────┐
│ tts-sidecar（Python CosyVoice2，zero-shot 克隆）  │
└───────────────────────────────────────────────┘
```

**关键分层**：
1. **不可变核心**：系统提示词、协议类型、pipeline 骨架 → 只读
2. **可精炼外壳**：记忆、画像、技能描述、自定义音色 → 可版本化演进（借鉴 Prime）
3. **语音优先**：录音→STT→唤醒判断→LLM→工具→TTS 状态机清晰分层（借鉴 HoloJarvis）
4. **主动运行**：mainloop 心跳 + 记忆维护（借鉴 BaiLongma）

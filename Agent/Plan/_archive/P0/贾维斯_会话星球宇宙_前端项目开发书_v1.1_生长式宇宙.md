## 一、项目概述

### 1.1 核心机制：生长式宇宙

```
初始状态                          生长过程                           成熟状态
┌─────────────┐                ┌─────────────┐                ┌─────────────────────┐
│             │   新建会话1    │      ●      │   新建会话N    │         ●           │
│     ●       │  ──────────►   │     /│\     │  ──────────►   │       / │ \         │
│   主星球     │                │    ●─●─●    │                │     ●──●──●──●      │
│  (家园星球)   │                │   主星球    │                │    /  主星球  \     │
│             │                │  中心引力源  │                │   ●────●────●────●   │
└─────────────┘                └─────────────┘                └─────────────────────┘
```

**核心规则：**
- **T0 时刻**：宇宙只有 1 个主星球（家园星球），代表"当前活跃会话"
- **T1 时刻**：用户新建会话 → 生成新星球，从主星球"分裂"出来，沿随机方向飞离
- **Tn 时刻**：每个星球可以继续"分裂"子会话，形成树状结构
- **所有星球始终受主星球引力约束**，不会飘散出宇宙边界

### 1.2 主星球（家园星球）定义

| 属性 | 值 | 说明 |
|------|-----|------|
| 位置 | (0, 0, 0) | 宇宙中心，永不移动 |
| 大小 | 固定半径 = 3.0 | 比普通星球大 2-3 倍 |
| 颜色 | 金色 #FFD700 | 视觉焦点，区别于普通星球 |
| 发光 | 脉冲式强光 | 呼吸灯效果，频率 2s |
| 标签 | "贾维斯" / "Jarvis" | 固定名称 |
| 功能 | 点击后进入"当前活跃对话" | 等同于"主页" |

```
用户操作触发                    前端处理                      视觉效果

└─────────────┘              └─────────────────┘           └─────────────────┘
                                      │
                                      ▼
┌─────────────┐              ┌─────────────────┐           ┌─────────────────┐
│ 4. 用户说    │◄─────────────│ 3. 对话进行中    │           │ 对话气泡显示    │
│ "新建一个    │              │   在当前会话内   │           │ 主星球脉冲加速  │
│  工作会话"   │              │   继续对话       │           │                 │
└──────┬──────┘              └─────────────────┘           └─────────────────┘
       │
       ▼
┌─────────────┐              ┌─────────────────┐           ┌─────────────────┐
│ 5. AI 理解   │────────────►│ 6. 调用新建会话   │           │ 主星球"分裂"    │
│   意图       │              │   API            │           │ 一道光束射出    │
└─────────────┘              └─────────────────┘           └─────────────────┘
                                      │
                                      ▼
┌─────────────┐              ┌─────────────────┐           ┌─────────────────┐
│ 8. 新星球    │◄─────────────│ 7. 后端返回新    │           │ 光束终点凝聚    │
│   生成完毕   │              │   会话数据       │           │ 形成新星球      │
│   进入对话   │              │   (id/topic/     │           │ 新星球沿轨道    │
│              │              │    embedding)    │           │ 开始运动        │
└─────────────┘              └─────────────────┘           └─────────────────┘
```

### 4.3 引力计算循环（每帧）

```typescript
function updatePhysics(planets: Planet[], deltaTime: number) {
  const G = 50; // 引力常数
  const HOME_MASS = 100; // 主星球质量
  const BOUNDARY = 100; // 宇宙边界

  for (const planet of planets) {
    // 1. 主星球引力
    const dirToHome = new Vector3(0,0,0).sub(new Vector3(...planet.position));
    const distToHome = dirToHome.length();
    const forceHome = dirToHome.normalize().multiplyScalar(
      G * HOME_MASS / (distToHome * distToHome)
    );

    // 2. 星球间斥力（防止重叠）
    let forceRepulsion = new Vector3(0,0,0);
    for (const other of planets) {
      if (other.id === planet.id) continue;
      const diff = new Vector3(...planet.position).sub(new Vector3(...other.position));
      const dist = diff.length();
      if (dist < 5) {
        forceRepulsion.add(diff.normalize().multiplyScalar(10 / (dist * dist)));
      }
    }

    // 3. 应用合力
    const acceleration = forceHome.add(forceRepulsion).multiplyScalar(1 / planet.mass);
    planet.velocity = new Vector3(...planet.velocity)
      .add(acceleration.multiplyScalar(deltaTime))
      .multiplyScalar(0.98); // 阻尼

    // 4. 更新位置
    planet.position = new Vector3(...planet.position)
      .add(new Vector3(...planet.velocity).multiplyScalar(deltaTime));

    // 5. 边界约束
    if (new Vector3(...planet.position).length() > BOUNDARY) {
      planet.velocity = new Vector3(...planet.velocity).multiplyScalar(-0.5);
      planet.position = new Vector3(...planet.position).normalize().multiplyScalar(BOUNDARY * 0.95);
    }
  }
}
```

| 风险 | 可能性 | 影响 | 应对 |
|------|--------|------|------|
| 引力系统不稳定（星球乱飞/聚集） | 中 | 高 | 预留调参时间；提供手动布局模式 |
| Whisper WASM 浏览器兼容性 | 中 | 高 | 准备后端 API fallback |
| 大量星球（>100）性能下降 | 高 | 中 | InstancedMesh；视锥剔除；性能模式 |
| 生长动画卡顿 | 中 | 中 | 对象池；动画用 GSAP 时间线控制 |

## 七、附录

### 7.1 API 契约（需后端配合）

```
// 创建新会话（触发星球分裂）
POST /api/v1/sessions
Body: { 
  title: string,           // 会话标题
  topic: string,           // 主题分类
  parentId?: string        // 父会话 ID（可选，无则直属主星球）
}
Response: {
  id: string,
  title: string,
  topic: string,
  createdAt: string,
  embedding: number[]      // 语义向量，用于同主题引力
}

// 获取会话列表（用于左侧导航）
GET /api/v1/sessions/tree
Response: {
  sessions: [
    { id, title, topic, parentId, messageCount, lastActiveAt, createdAt }
  ]
}

// 对话（WebSocket 更好）
POST /api/v1/sessions/:id/chat
Body: { message: string }
Response: { 
  reply: string,
  memoriesSaved: [{ id, content, type }]
}
```

### 7.2 关键参数表

| 参数 | 值 | 说明 |
|------|-----|------|
| 主星球半径 | 3.0 | 视觉中心 |
| 主星球质量 | 100 | 引力计算 |
| 普通星球基础半径 | 1.0 | 最小星球 |
| 引力常数 G | 50 | 调大引力强 |
| 阻尼系数 | 0.98/帧 | 速度衰减 |
| 宇宙边界 | 100 | 最大距离 |
| 最小星球间距 | 5 | 斥力触发距离 |
| 新星球初始距离 | 15-25 | 距主星球 |
| 分裂光束时长 | 0.8s | 动画时间 |
| 凝聚动画时长 | 0.5s | 动画时间 |
| 相机飞行时长 | 1.0s | 动画时间 |

## 1. 产品定位

**阿罗德斯**：一个带"人设"的 AI 语音对话桌面应用。核心价值 = 角色化陪伴对话 + 全语音交互（说话即问、出声即答）+ 记忆延续 + **本地优先（隐私不出本机、商业化零成本）**。

目标用户通过麦克风对话，系统以语音回复；保留文字输入作为降级。桌面端以独立窗口形式交付（Electron 壳），不依赖浏览器。

---

## 2. 核心域模型

### 2.1 会话（Session）
- 一个会话 = 一段有主题的连续对话，含多条消息
- 属性：标题、主题（work/life/creative/emotion/study/other）、创建/最后活跃时间
- **归档**（软删除）：归档后从列表隐藏，数据保留可恢复
- **过期回收**：超过 N 天（默认 30）未活跃的会话自动归档
- 归档态与活跃态由标签切换查看（会话/归档）

### 2.2 消息（Message）
- 属于某个会话；角色 user/assistant；来源 isVoice（语音/文字）
- 时间戳有序
- 每次 AI 回复带**唯一请求标识**（requestId），用于把流式碎片/完成/停止事件准确归位到对应请求

### 2.3 记忆（Memory）
- 从对话中自动提取（fact/preference/event/task），类型区分
- 关联会话，可被检索注入后续对话上下文
- **单一数据源**：仅经由记忆网关（LLM 分析闭环）写入与检索

### 2.4 语音引擎（TTS）
- **纯本地引擎**（离线、零成本、隐私不出本机）；不依赖任何云端语音服务
- 语音合成串行队列（防限流），失败指数退避重试（上限 5 次）
- **"声源"（音色）可自定义**：用户可上传自己的参考音频（3-10 秒）克隆专属音色，本地合成
- "声源"（音色参考音频，几 KB）与"模型"（生成引擎，大体积）分离——音色可定制，模型随本地环境分发
- **语音输出可关闭**：用户可随时关闭语音播报（静音模式），AI 只显示文字不发声；关闭状态下不再触发语音合成

### 2.5 语音识别（STT）
- 录音上传 → 服务端识别（Web 端）
- Electron 内禁用浏览器语音识别（不可用），走服务端识别

## 3. 关键业务流程

### 3.1 对话主流程
```
用户输入（语音/文字）
  → 分配请求标识
  → 保存用户消息
  → 检索相关记忆注入（单一记忆网关）
  → LLM 流式生成（碎片逐字推送，均带请求标识）
  → 本地语音合成播报（本地不可用则云端）
  → 对话后异步提取记忆（不阻塞主流程）
```

### 3.2 停止机制（核心交互语义）
> 用户"停止"的真实意图 = **不想再听**，而非"暂停后继续"

- **停止 = 三重中断**：停语音播放 + 停 LLM 推理 + 停任务执行
- 停止后：AI 不得继续输出、不得继续思考、不得在执行任务时失控
- 服务端不得再发送完成事件；前端清理等待状态
- 新消息 = 全新起点（自动取消上一个任务，绝不重播旧内容）
- 停止事件同样携带请求标识，确保只中断目标请求

### 3.3 记忆闭环
```
对话完成 → 记忆网关分析 → 提取新记忆 → 写入单一记忆库
下次对话 → 检索相关记忆 → 注入上下文 → 行为一致
```

### 3.4 请求-响应关联（通信协议）
- 每次对话请求有唯一标识，服务端所有相关事件（碎片/完成/停止/错误）回带同一标识
- 多个并发对话请求互不干扰：前端按标识认领各自的事件
- 取消/停止操作按标识定位到目标请求

## 4. 业务规则

| 编号 | 规则 |
|------|------|
| R1 | 当用户触发"停止"时，必须同时停止语音播放、LLM 推理与任务执行 |
| R2 | 当停止发生后，AI 不得再输出任何新内容、不得继续思考 |
| R3 | 当新消息发送时，必须取消上一个未完成请求（全新起点） |
| R4 | 当请求标识不匹配时，客户端必须忽略该事件（防串线） |
| R5 | 当语音输出为开启状态时，AI 回复必须用本地引擎合成播报 |
| R6 | 当语音输出为关闭状态（静音）时，必须不触发语音合成、不播报，只显示文字 |
| R7 | 当会话超过 30 天未活跃时，必须自动归档（可配置天数） |
| R8 | 当会话被归档时，必须从列表隐藏但保留数据；用户可随时恢复归档会话 |
| R9 | 当对话完成后，必须异步提取记忆，失败不得影响主对话回复 |
| R10 | 当记忆读写时，必须走单一记忆网关（禁止旁路写入） |
| R11 | 当请求数据校验失败时，必须返回明确错误且不执行后续逻辑 |
| R12 | 当语音合成失败时，必须按指数退避重试（最多 5 次）后仍失败才报错 |

## 5. 非功能需求

| 类别 | 要求 |
|------|------|
| 可用性 | 语音引擎全挂时仍可文字对话；TTS 失败不影响 LLM 回复 |
| 性能 | 首碎片延迟 < 3s；本地语音合成 < 5s（模型已加载时） |
| 可靠性 | 会话/记忆数据持久化；断线自动重连；并发对话请求不串线 |
| 可测试性 | 停止机制/归档/降级链必须有自动化测试（当前缺失，P0） |
| 安全 | API Key 存用户目录不入仓库；请求校验（zod）防畸形数据 |
| 可维护性 | 前后端共享类型定义（shared 层），schema 与类型同源 |

---

## 6. 边界与例外

- **本地语音引擎依赖本机环境**：GPU + 模型文件（大体积），exe 安装包不含模型，需单独部署
- **云端语音引擎**（后备）：依赖网络与第三方免费接口，可能失效——失效即本地
- **技能/工作流 Agent 路由尚未启用**（当前全部对话走主对话 Agent）
- **Electron 壳启动**：必须清除宿主环境注入的 Node 环境变量（否则启动崩溃）
- **不提供**：多用户账号体系、云端同步、移动端适配（均为未来可选）

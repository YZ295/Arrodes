# 阿罗德斯 · 子系统文档 SS-NAV
# 导航系统（Navigation System）

> 版本：v1.0  
> 代号：NAV  
> 优先级：P1  
> 负责人：Crow5（前端 UI 方向）
> 依赖：SS-UNI（宇宙核心引擎）完成后开发

---

## 一、模块定位

导航系统是用户在**阿罗德斯宇宙中定位和穿梭的罗盘**。当星球数量增多时，用户需要快速找到特定会话，导航系统提供搜索、列表、时间轴、书签等多种方式。

**不负责**：3D 渲染、语音处理、对话逻辑  
**负责**：搜索过滤、会话列表、时间轴、书签、主题过滤

---

## 二、核心概念

### 2.1 导航方式

```
用户想要找到"项目A"会话：

方式1：搜索 ──► 顶部搜索栏输入"项目A" ──► 匹配星球高亮 ──► 点击飞行
方式2：列表 ──► 左侧边栏展开树状列表 ──► 点击"项目A" ──► 相机飞行
方式3：书签 ──► 左侧书签栏点击收藏 ──► 直接飞行
方式4：时间轴 ──► 底部时间轴滑动 ──► 点击时间点 ──► 飞行到该时段星球
方式5：主题过滤 ──► 点击"工作"标签 ──► 只显示蓝色星球 ──► 点击飞行
```

## 三、功能需求

### 3.1 搜索栏

| 编号 | 需求 | 验收标准 |
|------|------|---------|
| NAV-001 | 顶部固定搜索栏，占位符"搜寻记忆..." | 始终可见 |
| NAV-002 | 实时搜索（输入即过滤） | 延迟 < 200ms |
| NAV-003 | 搜索范围：会话标题、摘要、消息内容 | 全覆盖 |
| NAV-004 | 匹配结果在宇宙中高亮（星球发光增强） | 视觉反馈 |
| NAV-005 | 搜索结果下拉列表（最多 5 条） | 显示标题+时间 |
| NAV-006 | 点击搜索结果，相机飞行到对应星球 | 1s 动画 |
| NAV-007 | 无结果时显示"未找到相关记忆" | 友好提示 |
| NAV-008 | 支持快捷键 Cmd/Ctrl + K 聚焦搜索 | 全局快捷键 |

### 3.2 会话列表（左侧边栏）

| 编号 | 需求 | 验收标准 |
|------|------|---------|
| NAV-101 | 左侧可折叠边栏，宽 280px | 默认展开 |
| NAV-102 | 树状结构显示所有会话 | 父子层级缩进 |
| NAV-103 | 节点显示：彩色圆点 + 标题 + 消息数 | 一目了然 |
| NAV-104 | 点击节点，相机飞行到对应星球 | 联动宇宙 |
| NAV-105 | 右键菜单：重命名 / 删除 / 收藏 | 操作便捷 |
| NAV-106 | 支持拖拽调整父子关系 | 拖拽后更新结构 |
| NAV-107 | 当前选中会话高亮 | 视觉区分 |
| NAV-108 | 边栏可折叠为图标栏 | 节省空间 |

### 3.3 书签系统

| 编号 | 需求 | 验收标准 |
|------|------|---------|
| NAV-201 | 星形图标收藏/取消收藏 | 点击切换 |
| NAV-202 | 收藏会话在列表顶部"书签"区显示 | 快速访问 |
| NAV-203 | 最多 10 个书签 | 超出提示替换 |
| NAV-204 | 书签持久化 | 刷新保留 |

### 3.4 时间轴

| 编号 | 需求 | 验收标准 |
|------|------|---------|
| NAV-301 | 底部时间轴，显示会话创建时间分布 | 可视化 |
| NAV-302 | 时间轴可缩放（日/周/月/年） | 滚轮缩放 |
| NAV-303 | 时间轴上的点代表会话，颜色=主题 | 直观 |
| NAV-304 | 点击时间点，飞行到最近会话 | 联动 |
| NAV-305 | 时间轴与宇宙视角同步 | 双向联动 |

### 3.5 主题过滤器

| 编号 | 需求 | 验收标准 |
|------|------|---------|
| NAV-401 | 顶部标签栏：全部 / 工作 / 生活 / 创意 / 情感 / 学习 | 点击切换 |
| NAV-402 | 选中标签，宇宙只显示对应颜色星球 | 其他星球半透明隐藏 |
| NAV-403 | 标签显示该主题会话数量 | 数字角标 |
| NAV-404 | 支持多选（Cmd/Ctrl + 点击） | 组合过滤 |

### 3.6 最近访问

| 编号 | 需求 | 验收标准 |
|------|------|---------|
| NAV-501 | 顶部显示最近 3 个访问会话 | 快捷入口 |
| NAV-502 | 点击直接飞行到星球 | 即时跳转 |

## 四、接口（与后端）

```typescript
// 搜索会话
GET /api/v1/sessions/search?q=关键词&limit=5
→ { results: [{ id, title, summary, matchedContent, score }] }

// 获取会话树（同 SRV）
GET /api/v1/sessions/tree
```

## 五、事件（与其他模块）

```typescript
// NAV 发出的事件
"nav:search:select" → 宇宙系统：相机飞行
"nav:list:select" → 宇宙系统：相机飞行
"nav:bookmark:click" → 宇宙系统：相机飞行
"nav:filter:topic" → 宇宙系统：过滤显示

// NAV 监听的事件
"universe:planet:click" → 更新列表选中态
"voice:session:switch" → 更新列表选中态
```

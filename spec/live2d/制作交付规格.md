# 白发角色 Live2D 首版制作包

状态：正面中性底稿与绑定规格已准备；未完成分层 PSD、网格绑定、moc3 导出及真实模型验收。底稿实际 1024×1536 RGB、角点 alpha=255，棋盘背景已烘焙进图像，需抠图补画；不是可直接导入的透明素材。

## 原画与拆层

保持既定白发冰蓝渐变、细辫、几何发夹、深蓝白色制服及成年角色形象。front-base.png 是合成参考底稿，不是分层文件；背景与边缘仍须检查处理。不得将多个整图副本称作分层。

PSD 建议至少 2048×3072，透明背景、统一画布坐标、每个可动部件独立图层。左右按角色自身方向命名。

- 后发、侧发左/右、刘海各束、细辫、发夹。
- 脸部底色（补全被刘海挡住的皮肤）、耳左/右、颈部。
- 每只眼分别拆眼白、虹膜、瞳孔/高光、上睫毛、下睫毛、眼皮；眉毛独立。
- 上唇、下唇、口腔、牙齿/舌头（需要时）。中性两眼睁开、闭嘴。
- 躯干、内衬、外套、领片、腰带及挂饰。
- 左右上臂、前臂、手套手掌；肩肘重叠区域补画，抬手后不得出现空洞。
- 后衣摆左右、短裤、左右腿与靴。

保留编辑版 arrodes_material_separation.psd；另存合并单部件后的 arrodes_import.psd。交付 .cmo3 与 .can3 源文件，保证后续可以改动。

## 绑定与动作

| 能力 | 参数/动作 | 验收 |
|---|---|---|
| 眨眼 | ParamEyeLOpen/ParamEyeROpen，EyeBlink 组 | 不穿帮，不永久眨单眼 |
| 呼吸 | ParamBreath / Idle 动作 | 胸肩轻动，身体不整体缩放 |
| 转头 | ParamAngleX/Y/Z | 首版限定小角度，刘海遮挡正确 |
| 说话 | ParamMouthOpenY / LipSync 组 | 播报时开合，停止后闭嘴 |
| 思考/肯定/疑惑/错误 | f02/f01/f03/f04 表情 | 状态切换可复位 |
| 提示与点击 | 提示抬手；TapBody/Shake/Head 点击组 | 动作完成回待机 |
| 头发衣摆 | physics3 | 无高频抖动或边界爆开 |

## 导出与集成

按 client/public/live2d/README.md 的路径交付 moc3、model3.json、纹理、物理、表情和动作。先确认当前 Web Core 与导出版本兼容，再导出。现有运行时并不意味着任何版本的模型都能直接加载。

## 验收边界

在 420×600 窗口验证脸部不被气泡遮挡、六种动作、TTS 停止闭嘴、资源加载失败回退、反复打开关闭不遗留 WebGL 资源。记录与游戏同时运行的帧率和 GPU 占用，未测前不承诺性能。

现阶段缺少 Cubism 编辑器操作能力和该角色的绑定资产。生成一张新图不能替代拆层补画与绑定。本制作包可交给具备 Cubism 的制作者继续，不代表版权清查或最终商用授权已经完成。

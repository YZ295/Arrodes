## Ticket 明细

### T-01 工作区智能体接入与连线

- 来源：FR-1、FR-2、FR-10、BR-3、BR-7
- 目标：用户能在工作区看到可接入的智能体，并把任意智能体「接入」（连线）或断开。
- 验收条件：
  - Given 工作区存在且本机有 Codex 与 Hermes；When 打开工作区；Then 两者以卡片形式列出并显示可用性。
  - Given 某智能体可用；When 用户点击「接入」；Then 它成为该工作区成员，界面出现已接入状态。
  - Given 某智能体不可用；When 用户尝试接入；Then 界面明确提示不可用，且不影响其他智能体。
  - Given 智能体已接入；When 用户点击「断开」；Then 它不再是该工作区成员。
  - Given 同一智能体已接入工作区 A；When 用户在另一工作区 B 接入同一智能体；Then 允许（可在多个工作区分属）。
- 前置依赖：无
- 规模：M
- 状态：done（2026-08-15）

### T-02 与智能体对话

- 来源：FR-3、FR-8、BR-6
- 目标：用户能在工作区与已接入的智能体进行多轮文字对话，历史可回溯，可随时中止。
- 验收条件：
  - Given 智能体已接入；When 用户选中它并发送消息；Then 智能体返回回复，展示在对话区。
  - Given 对话进行中；When 用户继续发消息；Then 智能体基于此前对话继续回答（多轮）。
  - Given 对话结束；When 用户重新打开该工作区；Then 历史对话仍在，可滚动回溯。
  - Given 智能体正在执行；When 用户选择中止；Then 执行停止并给出停止反馈。
  - Given 外部智能体不可用；When 用户发消息；Then 对话区给出明确错误提示。
- 前置依赖：T-01
- 规模：M
- 状态：done（2026-08-15）

### T-03 向智能体派发任务

- 来源：FR-4、BR-5、BR-6
- 目标：用户能向已接入的智能体派发一次性任务（例如"把登录页改成深色主题"），高风险任务需确认，执行后返回结果。
- 验收条件：
  - Given 智能体已接入；When 用户派发一次具体任务；Then 任务被执行并返回结果与说明。
  - Given 任务会改动文件或执行命令；When 执行即将开始；Then 出现确认提示，用户确认后才执行。
  - Given 用户拒绝确认；When 任务被取消；Then 不执行且界面反馈已取消。
  - Given 任务执行中；When 用户中止；Then 停止执行并反馈。
- 前置依赖：T-01（对话适配链路与 T-02 共用，建议 T-02 后实现）
- 规模：M
- 状态：done（2026-08-15）

### T-04 全量共享记忆与统一格式

- 来源：FR-5、FR-6、BR-1、BR-2
- 目标：工作区内所有已接入智能体共享同一份全部记忆；所有来源的记忆统一格式；外部智能体写入统一经阿罗德斯中转。
- 验收条件：
  - Given 智能体 A 在工作区写入一条记忆；When 智能体 B 查看同一工作区记忆；Then 能看到这条记忆，无需任何过滤或授权选择。
  - Given 不同智能体写入记忆；When 查看记忆列表；Then 每条记忆结构一致（来源、类型、内容、时间、归属工作区），不因来源不同而格式各异。
  - Given 用户查看某条记忆的来源；When 展示；Then 能识别来自哪个智能体。
  - Given 外部智能体要写入记忆；When 写入发生；Then 统一经阿罗德斯中转完成，外部智能体不直接写 Obsidian。
  - Given 某工作区；When 查询其共享记忆；Then 只返回该工作区的记忆（按工作区隔离）。
- 前置依赖：T-01
- 规模：M
- 状态：todo

### T-05 同步到 Obsidian

- 来源：FR-7、BR-4
- 目标：用户一键把工作区全部记忆以统一格式写入 Obsidian 知识库，并生成清单索引；重复同步不产生重复。
- 验收条件：
  - Given 工作区有若干条记忆；When 用户点击「同步到 Obsidian」；Then 全部记忆以统一格式出现在 Obsidian 知识库。
  - Given 同步完成；When 检查知识库；Then 存在记忆清单索引，列出全部条目。
  - Given 再次同步；When 重复执行；Then 不产生重复条目，已有条目按标识更新（幂等）。
  - Given 记忆有增删；When 再次同步；Then Obsidian 内容与工作区保持一致。
- 前置依赖：T-04
- 规模：S（基础能力已存在，主要补齐幂等与增删一致性验收）
- 状态：todo

### T-06 自由画布升级（backlog）

- 来源：FR-9、D6-B
- 目标：在卡片式布局验收通过后，支持拖拽定位与连线可视化。
- 验收条件（后续细化）：
  - Given 工作区；When 用户拖拽智能体卡片；Then 卡片可自由定位。
  - Given 智能体已接入；When 用户拖出连线；Then 以连线表示接入关系。
- 前置依赖：T-01（及卡片版验收）
- 规模：L（需拆解后实施）
- 状态：todo（backlog，不进入首批）

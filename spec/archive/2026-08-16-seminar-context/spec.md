# 行为规格：seminar-context

## ADDED Requirements

### REQ-SEMINAR_CONTEXT-001：滚动摘要

**必须**在研讨会历史文本超过阈值（默认 3000 字符）时，将早期轮次压缩为阶段摘要，
并只把「摘要 + 最近一轮原文」拼入后续 agent 的任务文本。

#### Scenario：长历史压缩

- **前置条件**：研讨会进行到第 2 轮，第 1 轮文本超过 3000 字符
- **当**：第 2 轮某 agent 发言
- **则**：其任务文本包含早期摘要与第 1 轮原文，总长不超过阈值 + 最近一轮长度

### REQ-SEMINAR_CONTEXT-002：短历史不变

**必须**在历史未超阈值时保持现行为（完整历史拼入任务）。

#### Scenario：短历史

- **前置条件**：1 轮 2 个 agent，历史不足 3000 字符
- **当**：第二方发言
- **则**：任务文本包含完整历史，无摘要段

### REQ-SEMINAR_CONTEXT-003：落库全量

**必须**保证 `workspace_seminar_messages` 仍保存每条发言全文，
学习提炼仍基于完整 transcript，不受滚动摘要影响。

#### Scenario：全量保存

- **前置条件**：研讨会发生滚动摘要
- **当**：查询消息列表/触发提炼
- **则**：消息完整，提炼使用全量记录

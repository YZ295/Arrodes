# 行为规格：security-release-hardening

## ADDED Requirements

### REQ-SECURITY_RELEASE_HARDENING-001：私有本地访问边界

阿罗德斯必须只接受属于当前应用使用者的敏感请求，且不得将动作、对话、文件、记忆或配置暴露给未授权网页、客户端或网络来源。

本次产品仅支持本机单用户：服务只在本机回环地址可达；桌面应用启动时建立的本地凭据是访问敏感 HTTP 和 WebSocket 能力的必要条件。健康检查不包含私有数据，可作为启动探测例外。

#### Scenario：非应用来源尝试访问敏感能力

- **前置条件**：阿罗德斯已运行，且请求方未获当前应用使用者授权。
- **当**：请求方尝试读取私有数据、发起对话、管理技能或处理待确认动作。
- **则**：请求被拒绝，不返回私有内容，也不改变应用状态。

### REQ-SECURITY_RELEASE_HARDENING-002：动作确认归属

每项待确认动作必须归属于发起它的工作区、会话和当前使用者；只有同一归属方可查看、确认或取消该动作。

“完整权限”或其他工作区设置不得绕过该归属和高风险确认要求。

#### Scenario：另一个会话发送确认短句

- **前置条件**：会话 A 有待确认动作，会话 B 正在连接。
- **当**：会话 B 发送确认、取消或关闭连接。
- **则**：会话 A 的待确认动作和运行任务保持不变。

### REQ-SECURITY_RELEASE_HARDENING-003：受授权的文件范围

文件浏览、读取、写入、创建、删除、移动和复制必须仅作用于当前所选项目的默认目录，以及用户明确授权给该工作区的额外目录；敏感或未授权范围不得被自动读取。目录授权可撤销，并在执行时生效。

系统必须将路径解析为规范化的真实位置，拒绝通过相对路径、同名前缀或符号链接逃出已授权根目录的请求；移动与复制的来源和目标均受此规则限制。

#### Scenario：请求工作区外的文件

- **前置条件**：目标不位于当前所选项目的默认目录或用户明确授权的额外目录。
- **当**：Agent 请求列出、读取或修改该目标。
- **则**：操作被拒绝，并向用户说明需要先授予目录访问权限。

### REQ-SECURITY_RELEASE_HARDENING-004：任务生命周期隔离

一个客户端连接的关闭、取消或异常不得取消其他客户端或会话的运行任务。

#### Scenario：连接中断

- **前置条件**：两个独立会话各有进行中的任务。
- **当**：其中一个会话的连接关闭。
- **则**：仅该会话自己的任务停止，另一会话继续运行。

### REQ-SECURITY_RELEASE_HARDENING-005：视觉内容安全处理

视觉功能必须只接受已声明支持的图片类型、在可预测的大小范围内处理请求，并在成功、校验失败或模型失败后清理临时内容。

#### Scenario：视觉模型请求失败

- **前置条件**：用户已上传一张有效格式图片。
- **当**：视觉分析失败或超时。
- **则**：用户收到一致的失败结果，临时图片不再保留。

### REQ-SECURITY_RELEASE_HARDENING-006：发布验证真实性

发布前质量命令必须只运行当前源码对应的测试，并在桌面交付前验证服务端、客户端和桌面产物是同一变更的结果。

#### Scenario：发布前验证

- **前置条件**：存在待发布的修复变更。
- **当**：运行标准验证。
- **则**：测试、类型检查、构建和依赖检查均可重复执行，并在失败时阻止发布。桌面打包前必须先重新生成服务端和客户端产物，避免打包历史 `dist` 内容。

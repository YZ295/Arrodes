# 技术设计：security-release-hardening

## 当前状态

用户已确认本机单用户边界，以及“所选项目目录默认 + 项目外目录须显式授权”的文件权限模型。本设计只覆盖当前干净基线；暂存在 `pre-security-release-hardening-user-wip` 的视觉/DSH 市场改动不恢复、不修改。

## 方案与数据流

### 本地访问身份

Electron 主进程为每次后端启动生成高熵临时凭据，并通过子进程环境变量传给服务端。后端只监听 `127.0.0.1`，并将受保护 HTTP 请求和 WebSocket 握手与此凭据绑定；桌面窗口在加载前将凭据写入仅本机、HttpOnly、SameSite=Strict 的会话 Cookie。`/api/health` 仅用于 Electron 启动探测，不返回用户数据或动作状态。

服务端对带 `Origin` 的请求要求来源为当前 Electron/Vite UI 来源；不再开放跨域访问。WebSocket 在升级前执行同样的来源和凭据校验。这样网页、其他本机进程或局域网客户端即使知道端口，也不能读取或触发敏感 API；开发模式仍由 Electron 注入相同临时凭据，不能静默降级为开放服务。

### 动作与会话归属

每个 WebSocket 连接拥有独立的进行中任务表。取消和连接关闭只处理该表中的控制器；同一会话发起新任务会显式中断该连接中先前任务，并在 `finally` 中仅清理自身控制器。

高风险技能调用在异步上下文中取得 `{ localUserId, workspaceId, sessionId }`，并在待确认项中保存该所有权。文本确认和 REST 确认均从已存在会话派生同一所有权，再仅查询匹配项；动作列表不暴露其他会话的参数或确认入口。全局“完整权限自动批准”被移除，高风险动作始终经确认闸门。

### 文件能力边界

工作区配置增加 `authorizedDirs`：`projectDir` 是已选择项目时的默认根；额外目录只能由用户在 UI 中明确添加，且可单独撤销。无项目根或额外授权时，文件技能拒绝执行。

文件执行器在每次读取或写入前从当前工作区重新取得授权根，以便撤销立即生效。它对现有路径解析真实路径，对新建目标解析最近存在的父目录；之后检查结果是否位于任一规范化授权根内。移动和复制分别验证源与目标。授权上下文随待确认动作保存为工作区/会话身份而非一份可过期的路径快照。

### 视觉与发布

视觉路由统一限制图片为 JPEG、PNG、GIF、WebP，最大解码后 10 MiB，并将 JSON 请求体上限设置为能承载该限制的固定值。服务校验 Base64 结构、大小、文件签名与声明格式；所有 multipart 临时文件都在 `finally` 和上传错误路径中清理。远端视觉请求加入明确超时。

服务端测试脚本限定 `src`，避免执行历史构建产物；桌面 `pack` / `dist` 在 Electron 编译前重新构建服务端和客户端。依赖审计修复只接受最小锁文件或直接依赖变化，并复跑完整验证。

## 接口与兼容性

必须保持桌面单用户体验可用；健康检查保持无凭据用于主进程就绪探测。受保护 API 在缺失或错误本地凭据时返回统一的未授权错误；非允许 Origin 返回拒绝错误。动作确认 API 增加 `sessionId`，从服务器端会话记录导出工作区，不能由客户端声称任意所有权。

工作区更新 API 接受并返回规范化的 `authorizedDirs`，客户端在现有项目选择器旁提供“授权额外目录”和撤销入口；已有 `projectDir` 数据无需迁移。未选择项目目录的工作区不再继承进程工作目录作为文件技能根。

## 配置、常量与依赖注入

- `ARRODES_LOCAL_TOKEN`：Electron 每次启动生成；服务端没有该值时不得以开放模式启动敏感能力。
- `ARRODES_UI_ORIGIN`：Electron 传递其实际加载的 UI 来源，开发时为 Vite 来源，生产时为本机服务来源。
- `projectDir`、`authorizedDirs`：工作区配置，不通过环境变量或路径黑名单表达。
- 图片大小、超时和支持格式：命名常量，在路由与视觉服务之间复用。

## 备选方案与取舍

- 仅绑定回环、不设凭据：不能阻止恶意网页或其他本机进程访问本机 API，拒绝。
- 将令牌写入客户端 JavaScript：容易被 XSS 或第三方页面读取，拒绝；使用 HttpOnly Cookie。
- 全局自动批准：一个工作区设置会改变其他工作区的高风险操作，拒绝。
- 路径黑名单：不能阻止未列出的隐私目录、前缀碰撞或符号链接逃逸，拒绝。

## 失败模式、安全与回滚

令牌错误、来源错误、未选择目录、目录授权撤销、路径逃逸、动作所有者不匹配均拒绝且不执行。启动缺少令牌时明确失败；不得静默回退到开放 CORS 或全盘文件访问。发布脚本失败不得继续 Electron 打包。

若紧急回滚本次代码，只能回退整个已验证变更；不得通过临时移除令牌、重新启用开放 CORS 或恢复全局自动批准来“修复”启动问题。

## 数据迁移

`none`。工作区既有 JSON 配置通过读取时兼容：缺失 `authorizedDirs` 等价于空列表。无数据库模式变更或不可逆数据迁移。

# 桌面管家投影层验收

## 目标

在不复制视觉与 Agent 后端的前提下，把主窗口产生的结构化屏幕观察投影到一个固定尺寸、透明、置顶、鼠标穿透的桌宠窗口。

## 首版验收场景

1. 启动桌面应用后，主窗口与 420×600 桌宠窗口同时出现，桌宠位于主屏幕工作区右下角。
2. 未开启观察时，桌宠明确显示“未观察”，不得暗示正在采集。
3. 主窗口开启屏幕观察后，桌宠能够显示当前应用、当前状态和最多一条下一步建议。
4. 置信度低于 0.55 时不显示建议，并展示一个不确定点或“证据还不足”。
5. 识别到用户正在编写提示词时，具体提示词修改意见优先于泛化下一步。
6. 桌宠不获取焦点、默认穿透鼠标、跳过任务栏，并启用内容保护以降低被自身屏幕采集再次识别的风险。
7. 关闭主窗口后应用整体退出，不遗留失去观察来源且无法操作的桌宠窗口。

## 明确不通过

- 仅定时生成一段自由文本，没有应用、状态、建议、置信度和不确定性字段；
- 低置信度仍给出游戏操作或文件操作建议；
- 桌宠自己再次进入截图并持续触发视觉分析；
- 为桌宠复制一套屏幕捕获或视觉模型实例；
- 宣称无需特定游戏样本即可稳定识别所有 HUD 状态。

## 后续而非首版

- 托盘入口、拖拽定位、多显示器位置记忆；
- 交互模式与穿透模式切换；
- 指定游戏的 HUD 适配器与回放样本集；
- 经确认的文件处理或其他电脑操作。

# 变更提案：frontend-aesthetics

## 问题与背景

阿罗德斯主界面存在全局样式覆盖 Tailwind 间距、390px 窄屏被固定侧栏裁切、状态与错误重复、键盘焦点不可见，以及低对比和装饰性动效过多的问题。

## 目标

建立“Precision Workspace / 精密工作台”黑蓝视觉系统；改善层级、可读性、响应式、状态呈现与键盘操作，同时保留全部产品行为、安全边界、壁纸和头像能力。

## 非目标

不修改路由、服务端协议、安全逻辑、数据模型或用户原有 stash；不引入动画框架或新运行时依赖。

## 影响范围

客户端全局样式、应用壳、侧栏、状态栏、对话区、输入栏、抽屉面板及现有确认/工作区面板的视觉层。

## 风险

响应式条件可能影响桌面布局；视觉调整可能误伤确认会话 ID 和目录授权交互。通过纯布局工具测试、完整客户端测试、构建及桌面/窄屏截图控制风险。

## 验收标准

桌面形成清晰三层表面；390px 主任务区可用；状态错误只出现一次且不重叠；交互元素有可见焦点；动效支持 reduced-motion；既有测试和构建通过。

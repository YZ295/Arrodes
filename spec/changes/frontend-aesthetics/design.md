# 技术设计：frontend-aesthetics

## 当前状态

React 19 + Tailwind 4。未分层的全局通配重置位于 Tailwind 导入之后，可能覆盖工具类间距；固定侧栏没有窄屏策略；状态错误存在两个渲染所有者。

## 方案与数据流

以 Impeccable Operate 模式主导，Hallmark 仅用于审计。新增无副作用布局策略工具，按宽度输出紧凑导航决策；组件继续消费现有 store/hook 数据，只调整结构类和表现。StatusBar 成为状态唯一所有者。

## 接口与兼容性

不改变服务端接口或组件业务回调。保留 ConfirmDialog 的 `sessionId` 和 WorkspacePanel 的授权目录调用。

## 配置、常量与依赖注入

颜色、尺寸、圆角、阴影、动效时长集中为 CSS 语义变量；布局断点与宽度以命名常量存在纯函数中。无新依赖。

## 备选方案与取舍

不加入图标库，避免依赖审批和大范围 SVG 重写；不使用 GSAP，常规 CSS 过渡足够。

## 失败模式、安全与回滚

错误断点可能压缩内容，通过纯函数单测和真实 390/1440 截图验证。安全相关 props 不改。单独分支可整体回滚。

## 数据迁移

`none`。

## 打包桌面版（Electron）

```bash
cd desktop
npm run dist  # 或 npx electron-builder --win nsis --config.directories.output=releaseN
```

- 产物：`releaseN/Arrodes-Setup-1.0.0.exe`（NSIS 安装包）+ `win-unpacked/`（免安装）
- **extraResources**：server（dist+node_modules）/ client/dist / **tts-sidecar 脚本**
- **模型不入包**（5.3GB）→ 运行时 `COSYVOICE_PROJECT_DIR` 指向本机模型项目

### 打包避坑（Windows 沙箱环境）

| 坑 | 解决 |
|----|------|
| PyInstaller 覆盖旧 exe 被沙箱拦 | 用 `--distpath dist2` 独立输出目录 |
| electron-builder 卡在 release3 | `--config.directories.output=release4/5/6` 换新目录 |
| dev 后端占 3002 导致打包版端口冲突 | 冒烟前先停 dev 后端 |
| 打包版 server 找不到侧车脚本 | extraResources 必须含 tts-sidecar |

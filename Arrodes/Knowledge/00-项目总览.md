# 00 · 项目总览

## 定位

**阿罗德斯（Arrodes）**——一个**持续运行的桌面语音 AI Agent**，不是普通聊天程序：

- 🎙️ **语音优先**：本地 CosyVoice2 语音合成（零成本、离线、隐私不出本机）
- 🧠 **长期记忆**：SQLite 记忆库 + 会话总结 + 画像，主动整理去重
- ⏱️ **主循环驱动**：30s tick，空闲心跳 / 到期提醒推送 / 定期记忆整理
- 🤖 **多 Agent 路由**：按意图分发到 main / memory / dev
- 🖥️ **双形态**：Web（浏览器）+ 桌面（Electron 安装包）+ 桌宠（独立 exe）

## 技术栈

| 层 | 技术 |
|----|------|
| 后端 | Node.js + TypeScript + Express + WebSocket + better-sqlite3 |
| 前端 | React + Vite + TailwindCSS + thinking-orbs |
| 语音 | Python + FastAPI + CosyVoice2（conda 环境 `cosyvoice`） |
| 桌宠 | Python + PyQt6（PyInstaller 打包） |
| 桌面壳 | Electron 31 + electron-builder（NSIS） |
| 测试 | Vitest（server 69+ 测试） |
| CI | GitHub Actions（.github/workflows/ci.yml） |

## 端口约定

| 端口 | 服务 | 说明 |
|------|------|------|
| 3002 | 主后端 | REST + WS（/v1/chat）+ 静态托管前端 |
| 12001 | TTS 侧车 | CosyVoice2 FastAPI（懒启动，失败自动拉起） |

## 启动方式

```bash
# 1. 后端（生产模式，托管 client/dist）
cd server && NODE_ENV=production PORT=3002 node dist/index.js

# 2. 前端开发模式（热更新）
cd client && npm run dev

# 3. 语音侧车（一般无需手动，后端首次合成自动拉起）
conda run -n cosyvoice python tts-sidecar/tts_sidecar.py --port 12001
```

> 依赖前置：cosyvoice conda 环境（Python 3.10）+ CosyVoice2-0.5B 模型（`tts-sidecar/CosyVoice-unzip/cosyvoice-main/pretrained_models/`，约 5.3GB）。

## 关键设计决策

1. **WS + requestId 协议**（优于 SSE）：全双工、可取消、可关联请求/响应
2. **本地语音优先**：隐私优势，云端 TTS 已移除
3. **better-sqlite3**（同步）而非 ORM：简单可靠
4. **Prompt 分层**：不可变核心（SYSTEM_PROMPT）+ 可精炼外壳（promptShell，版本化回滚）

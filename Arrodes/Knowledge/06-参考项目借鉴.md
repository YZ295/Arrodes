# 06 · 参考项目借鉴

阿罗德斯对标三个"先驱"开源项目（均已克隆到用户仓库），逐项评估迁移。完整分析见 `Plan/bailongma-借鉴分析.md` 与 `Plan/master-plan-v2.md`。

## 对比总览

| 维度 | BaiLongma | HoloJarvis | Prime Agent | Arrodes |
|------|-----------|-----------|-------------|---------|
| 形态 | 持续运行桌面 Agent | 语音管家（全息投影） | 自我改进编码 Agent | 持续运行桌面语音 Agent |
| 协议 | SSE | - | - | **WS + requestId（更强）** |
| 语音 | 云端 | 云端 + 克隆回退 | - | **本地 CosyVoice2（隐私优势）** |
| 主循环 | ✅ | ✅ | daemon | ✅（阶段1 落地） |
| 记忆整理 | ✅ 主动整理 | 显式指令 | - | ✅（阶段1/2 落地） |
| Agent 路由 | - | - | 单工具模型/递归子代理 | ✅（阶段3 落地） |
| 提示词分层 | - | - | 不可变核心+可精炼外壳 | ✅（阶段4 落地） |

## BaiLongma（持续运行 Agent）

**借鉴落地**：
- ✅ **主循环**：`mainloop.ts` 30s tick（提醒/记忆整理/状态）
- ✅ **记忆去重合并**：`consolidateMemories`（Dice bigram 相似度）
- ✅ **人物卡片**：`extractPersonEntities` + 前端人物卡
- ⏭️ **社交连接器**（Discord/微信）：远期 backlog（复杂度高）

**明确保留不学**：WS 协议 / React UI / 本地语音 / better-sqlite3（Arrodes 已更强或更合适）

## HoloJarvis（语音管家）

**借鉴落地**：
- ✅ **显式记忆指令**："记住X / 忘了X" 直达记忆库秒回（`explicitMemory.ts`）
- ✅ **TTS 失败回退**：自定义音色失败 → 默认音色重试
- ✅ **状态色联动**：聆听蓝/思考金/说话青（AgentStatusOrb 光晕）
- ✅ **工具补全**：报时/提醒已有 + 天气新增（Open-Meteo 免 key）
- ⏭️ 拼音模糊唤醒 / 17 工具全量 / MCP：按需

## Prime Agent（自我改进 Agent）

**借鉴落地**：
- ✅ **Prompt 分层**：不可变核心 + 可精炼外壳（版本化回滚）→ `promptShell.ts`
- ✅ **多 Provider 配置**：自定义模型持久化 + 设置 UI
- ✅ **CI 纪律**：`.github/workflows/ci.yml`（server 测试 + client 构建）
- ⏭️ 单工具模型（每工具独立 LLM）：成本高，暂缓
- ⏭️ 递归子代理：dev Agent 的技能 Loop（≤3 轮）已近似，未做全递归

## 借鉴原则

1. **不照搬代码**，按 Arrodes 特点适配（协议/UI/本地语音是优势，不学劣势）
2. 每条借鉴带**验收标准**（测试 + E2E 验证）
3. 高风险项带**开关/回滚**（如 HARNESS_ROUTING=off）

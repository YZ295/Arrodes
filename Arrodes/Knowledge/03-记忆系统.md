# 03 · 记忆系统

## 存储（better-sqlite3）

- 表：`memories`（id / sessionId / content / type / createdAt）
- 类型：`fact`（事实）/ `preference`（偏好）/ `event`（事件）/ `task`（待办）
- 库路径：`server/data/*.db`

## MemoryGateway（services/MemoryGateway.ts）

### 提取（对话后）

- 对话结束后 memory Agent 后台调度 → LLM 分析 → `parseAnalysisJson` 解析
- 提取 memories（内容+类型）+ profile（用户画像）→ 入库

### 召回（retrieveContext）

- 用户新消息 → `extractKeywords` 提取关键词 → `memoryRepo.searchAll(keywords)`（created_at DESC）
- 排除当前会话 → 排名取前 5 条注入上下文

### 召回排序（rankMemories）— 阶段 2 新增

- **关键词命中数** × **时间衰减** 加权，纯函数可单测
- 让"相关 + 新近"的记忆排前面

### 人物识别（extractPersonEntities）— 阶段 2 新增

- 英文人名：首字母大写单词（排除常见词）
- 中文人名：**常见姓氏 + 1 个字**（2 字人名最可靠；3 字易误报不收）
- 黑名单排除"高兴/喜欢"等误报
- 记忆 API 返回 `persons` → 前端人物卡展示

### 去重合并（consolidateMemories）— 阶段 1 新增

- `computeDuplicateGroups(memories, threshold=0.75)` 纯函数：
  - 分组：同会话 + 同类型
  - 组内两两比较：**Dice 系数（字符 bigram）** 相似度 ≥ 0.75 → 重复
  - 保留较早（createdAt 前），删除较晚
- `consolidateMemories(repo=memoryRepo)` 执行删除，返回 {merged, removed}
- 触发：mainloop 每 3 次 tick（90s）一次

> 相似度算法演进：词 Jaccard（中文失效）→ 字符 bigram Jaccard → **Dice（对单字插入更宽容）**。
> 阈值 0.85 太激进（中文短文本措辞变体只有 0.7 左右），降到 0.75 保守防误删。

## 显式记忆指令（services/explicitMemory.ts）— 阶段 1 新增

用户消息在 **WS handler 拦截，不走 LLM 秒回**：

| 指令 | 行为 |
|------|------|
| `记住X` / `记一下X` | 直接写记忆库，自动推断类型（偏好/事件/待办）→ "记住了：X（已保存为偏好记忆）" |
| `忘了X` / `忘记X` | LIKE 匹配删除 → "已忘记关于「X」的 N 条记忆" |
| `我有什么记忆` | 列出当前记忆 |

## 二、关键决策详解

### 决策 1：主星球要更复杂（B）

**现状问题**：
- 星球是低模多边形（分段数低）
- 星星是正方形（PointsMaterial 默认是方形粒子）
- 没有大气层散射效果

**MVP 目标**：
- ✅ 星球分段数 64x64（圆润）
- ✅ 星星改为圆形（自定义纹理或 Shader）
- ✅ 大气层散射（菲涅尔效果）
- ✅ 表面纹理（程序化噪点）

**后续迭代（非 MVP）**：
- 表面细节（陨石坑、大陆轮廓）
- 动态云层
- 极光效果

---

### 决策 2：对话框可拖动 + 可吸附（B + C）

**B（可拖动）**：
- 鼠标按住标题栏，可以拖动对话框到屏幕任意位置
- 拖动时对话框半透明（opacity: 0.8）
- 释放后恢复正常

**C（可吸附）**：
- 当对话框靠近屏幕边缘（距离 < 50px）时，自动吸附到边缘
- 吸附方向：左/右/下（不支持上边缘，避免遮挡）
- 吸附后只露出 10px 的"把手"，点击把手展开

**两者结合**：
```
用户拖动对话框 → 靠近右边缘 → 自动吸附 → 只露出把手
→ 点击把手 → 对话框展开 → 可以再次拖动
```

**技术实现**：
- 使用 Framer Motion 的 `drag` 属性
- 监听 `onDragEnd` 事件，计算距离边缘的距离
- 吸附动画使用 `animate` 到边缘坐标

---

### 决策 3：语音流程 A（录音 → 自动发送）

**流程**：
```
1. 点击麦克风按钮（变红）
2. 开始录音，显示圆形粒子音波
3. 再次点击或静音 3s 自动结束
4. 自动转文字并发送（无需用户确认）
5. 显示"思考中..."
6. AI 回复逐字显示 + 语音播放
```

**优点**：快速、流畅，符合语音交互直觉
**风险**：转录错误时无法修改（后续可加"撤回"功能）

---

### 决策 4：新建会话触发 C（语音 + UI）

**语音触发**：
- 用户说"新建一个工作会话"
- AI 识别意图 → 创建会话 → 触发星球生长动画

**UI 触发**：
- 对话框右上角有"+"按钮
- 点击后弹出菜单：工作 / 生活 / 创意 / 情感 / 学习 / 其他
- 选择后创建对应主题会话

**两者并存**：
- 熟练用户用语音（快）
- 新用户用 UI（直观）

---

### 决策 5：AI 风格先 B 后 C

**MVP（先 B）**：
- 现代简洁风格
- "好的，已为你创建工作会话"
- "明天下午 3 点开会，已记录"

**后续加 C（可配置）**：
- 设置面板选择风格：现代 / 古典 / 可爱
- 古典："遵命，愚者大人。在下已为您开辟新领域。"
- 可爱："好哒~ 已经帮你建好新的工作星球啦 ✨"

---

**后续迭代**：翡翠、蔷薇等更多主题

---

### 决策 7：移动端适配（A）

**MVP 要求**：
- 对话框全屏显示（移动端屏幕小）
- 触摸操作：单指旋转宇宙，双指缩放
- 麦克风按钮更大（便于触摸）
- 消息气泡宽度 90%（避免边缘太窄）

**技术方案**：
- 使用 CSS Media Query 判断屏幕宽度
- 小于 768px 时切换为移动端布局
- OrbitControls 开启触摸支持

---

### 决策 8：离线模式（A）

**MVP 要求**：
- 检测网络状态（在线/离线）
- 离线时显示提示横幅
- 本地 STT（Web Speech API 可用）
- 本地 TTS（Web Speech API 可用）
- 消息本地缓存（IndexedDB）
- 联网后自动同步

**限制**：
- 离线时无法创建新会话（需要后端）
- 离线时 AI 回复为预设模板（无法调用 LLM API）

---

### 决策 9：数据持久化先 A 后 B

**阶段 A（本地存储）**：
- 消息历史：localStorage / IndexedDB
- 用户设置：localStorage
- 会话列表：IndexedDB
- 语音模型缓存：IndexedDB

**阶段 B（云端同步）**：
- 用户登录系统
- 数据加密上传到服务器
- 多设备同步
- 数据备份/恢复

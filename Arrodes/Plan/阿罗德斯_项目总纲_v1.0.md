## 一、世界观与产品定位

### 1.1 世界观

> **"每一次对话，都是宇宙中的一颗星球。"**

阿罗德斯（Arodes）是愚者（用户）的仆人，存在于一个由对话记忆构成的微型宇宙中。

- **主星球「阿罗德斯之心」**：金色，位于宇宙中心，代表"当前活跃对话"
- **会话星球**：围绕主星球生长，每个星球是一个独立会话/话题
- **子星球**：从父星球分裂，代表子话题
- **记忆星云**：连接相关星球的微弱光丝，代表跨会话的记忆关联

### 1.2 角色设定

| 属性 | 设定 |
|------|------|
| 名字 | 阿罗德斯（Arodes）|
| 身份 | 愚者的仆人 |
| 性格 | 忠诚、谦逊、略带神秘、知识渊博 |
| 语气 | 正式但温和，偶尔引用古典文学 |
| 自称 | "您的仆人""在下" |
| 对用户的称呼 | "愚者大人""主人"（可自定义）|
| 边界 | 绝不僭越，绝不欺骗，绝对忠诚 |

### 1.3 核心体验

1. **打开阿罗德斯** → 看到微型宇宙，中央金色主星球微微脉动
2. **点击主星球** → 展开语音对话，阿罗德斯以语音回应
3. **自然对话** → 聊工作、生活、创意，阿罗德斯记住一切
4. **说"新建一个工作会话"** → 一道光束从主星球射出，凝聚成蓝色新星球
5. **点击新星球** → 进入该话题的专属对话空间
6. **探索宇宙** → 拖拽旋转、缩放，看到所有话题如星系般分布

## 三、开发原则

### 3.1 给 Crow5 的十条铁律

1. **每个模块独立开发，独立验收**，不要串在一起做
2. **先跑通数据流，再打磨视觉效果**
3. **Mock 数据先行**，后端接口没好之前用假数据
4. **事件驱动**，模块间通过 Event Bus 通信，不要直接调用
5. **接口契约优先**，前后端先对齐 API 格式再写代码
6. **移动端可用**，但不是优先，桌面端体验第一
7. **性能底线**：100 个星球 ≥ 45fps
8. **错误处理每个接口都要有**，不要假设网络永远通
9. **代码即文档**，每个函数写 JSDoc，复杂逻辑写注释
10. **每日可演示**，每天结束要有一个能跑的效果

### 3.2 技术栈（全栈统一）

| 层级 | 技术 | 版本 | 理由 |
|------|------|------|------|
| 前端框架 | React 19 + TypeScript | ^19.0.0 | 生态成熟 |

## 四、接口契约（前后端对齐）

### 4.1 会话相关

```typescript
// 创建会话（触发星球生长）
POST /api/v1/sessions
Request: {
  title: string;           // 会话标题
  topic: "work" | "life" | "creative" | "emotion" | "study" | "other";
  parentId?: string;       // 父会话 ID，无则直属主星球
  initialMessage?: string; // 可选初始消息
}
Response: {
  id: string;
  title: string;
  topic: string;
  parentId: string | null;
  embedding: number[];     // 语义向量，用于同主题引力
  createdAt: string;       // ISO 8601
}

// 获取会话树
GET /api/v1/sessions/tree
Response: {
  sessions: SessionNode[];
}

interface SessionNode {
  id: string;
  title: string;
  topic: string;
  parentId: string | null;
  messageCount: number;
  lastActiveAt: string;
  createdAt: string;
  children?: SessionNode[]; // 子会话
}

// 获取单个会话详情
GET /api/v1/sessions/:id
Response: SessionNode & {
  summary: string;         // AI 生成的会话摘要
  keyMemories: MemoryNode[];
  messages: Message[];
}

interface MemoryNode {
  id: string;
  content: string;
  type: "fact" | "preference" | "event" | "task";
  createdAt: string;
}

interface Message {
  id: string;
  role: "user" | "assistant";
  content: string;
  timestamp: string;
  isVoice: boolean;
}
```

### 4.2 对话相关

```typescript
// 发送消息（WebSocket 优先）
WS /v1/chat
Client → Server: {
  type: "message";
  sessionId: string;
  content: string;
  isVoice: boolean;
}

Server → Client: {
  type: "chunk" | "complete" | "memory" | "intent";
  data: {
    // chunk: { content: string }  // 流式回复片段
    // complete: { content: string, memories: MemoryNode[] }
    // memory: { memories: MemoryNode[] }  // 实时记忆反馈
    // intent: { type: string, params: object }  // 意图识别结果
  }
}

// HTTP 备选（非流式）
POST /api/v1/sessions/:id/messages
Request: { content: string; isVoice: boolean; }
Response: {
  reply: string;
  memories: MemoryNode[];
  intent?: IntentResult;
}
```

### 4.3 语音相关

```typescript
// 上传音频转文字（云端 Whisper fallback）
POST /api/v1/voice/transcribe
Content-Type: multipart/form-data
Body: { audio: File }
Response: {
  text: string;

Request: { text: string; voice?: string; speed?: number; }
Response: {
  audioUrl: string;        // 音频文件 URL

}
```

## 五、事件总线契约（模块间通信）

```typescript
// 宇宙系统 ↔ 语音系统 ↔ 导航系统 的事件定义

// ===== 语音系统 发出的事件 =====
interface VoiceEvents {
  // 用户开始录音
  "voice:recording:start": void;

  // 用户结束录音，转录完成
  "voice:recording:end": { text: string; sessionId: string };

  // 用户发送消息
  "voice:message:send": { content: string; sessionId: string; isVoice: boolean };

  // AI 回复开始
  "voice:reply:start": { sessionId: string };

  // AI 回复完成
  "voice:reply:complete": { content: string; sessionId: string; memories: MemoryNode[] };

  // 识别到系统意图
  "voice:intent:detected": { type: string; params: object; rawText: string };

  // 请求新建会话
  "voice:session:create": { title: string; topic: string; parentId?: string };

  // 请求切换会话
  "voice:session:switch": { sessionId: string };
}

// ===== 宇宙系统 发出的事件 =====
interface UniverseEvents {
  // 用户点击星球
  "universe:planet:click": { sessionId: string; title: string };

  // 用户双击星球（进入对话）
  "universe:planet:doubleclick": { sessionId: string };

  // 新星球生成动画完成
  "universe:planet:spawned": { sessionId: string; title: string; topic: string };

  // 相机飞行完成
  "universe:camera:arrived": { target: string }; // "home" | sessionId

  // 用户拖拽星球调整位置
  "universe:planet:moved": { sessionId: string; position: [number, number, number] };
}

// ===== 导航系统 发出的事件 =====
interface NavEvents {
  // 用户搜索并选择
  "nav:search:select": { sessionId: string };

  // 用户从列表选择
  "nav:list:select": { sessionId: string };

  // 用户点击书签
  "nav:bookmark:click": { sessionId: string };

  // 用户切换主题过滤器
  "nav:filter:topic": { topic: string | "all" };
}

// ===== 全局事件 =====
interface GlobalEvents {
  // 应用初始化完成
  "app:ready": void;

  // 网络状态变化
  "network:status": { online: boolean };

  // 错误通知
  "app:error": { message: string; code: string };
}
```

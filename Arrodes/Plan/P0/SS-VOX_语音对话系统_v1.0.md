# 阿罗德斯 · 子系统文档 SS-VOX
# 语音对话系统（Voice Dialogue System）

> 版本：v1.0  
> 代号：VOX  
> 优先级：P0  
> 负责人：Crow5（前端 UI + 语音方向）

---

## 一、模块定位

语音对话系统是用户与阿罗德斯**直接对话的窗口**。它是一个悬浮在宇宙界面上的对话面板，支持语音输入和文字输入，负责将用户的声音转化为与 AI 的交互。

**不负责**：3D 渲染、星球生成、引力计算  
**负责**：音频采集、语音转文字、对话管理、文字转语音、意图识别触发

---

## 二、核心概念

### 2.1 对话模型

```
阿罗德斯的对话遵循"仆人"角色设定：

用户："阿罗德斯，帮我记一下明天下午三点开会。"
阿罗德斯："遵命，愚者大人。已为您记录：明日申时三刻，有会议待赴。"
        [💾 已记住：明天下午3点开会]

用户："新建一个工作会话，关于项目A。"
阿罗德斯："如您所愿。已为大人开辟「项目A」之领域。"
        [触发宇宙系统：新星球生长动画]
        [自动切换到新项目A会话]

用户：（在项目A会话中）"我记得之前说要调研竞品？"
阿罗德斯："正是，大人。三日之前，您曾吩咐在下留意同行动向。"
        [从 Hermes 检索记忆并引用]
```

### 2.2 对话窗生命周期

```
隐藏状态 ──► 最小化（右下角圆形按钮，显示未读数）
    │
    ▼ 点击主星球 / 点击新星球 / 点击悬浮按钮
展开状态 ──► 完整对话窗（可拖动、可调整大小）
    │
    ▼ 点击最小化按钮 / 点击宇宙空白处
最小化 ──► 缩回右下角
    │
    ▼ 点击关闭按钮
隐藏 ──► 完全隐藏（可通过点击星球重新唤起）
```

## 四、接口（与后端）

```typescript
// 通过 WebSocket 发送消息
WS /v1/chat
Client → Server: {
  type: "message";
  sessionId: string;
  content: string;
  isVoice: boolean;
}

// 接收流式回复
Server → Client: {
  type: "chunk";        // 流式片段
  data: { content: string };
}

Server → Client: {
  type: "complete";     // 回复完成
  data: { 
    content: string;
    memories: MemoryNode[];
  };
}

Server → Client: {
  type: "memory";       // 实时记忆反馈
  data: { memories: MemoryNode[] };
}
```

## 五、事件（与其他模块）

```typescript
// VOX 监听的事件
"universe:planet:click" → 如果是普通星球，展开对话窗
"universe:planet:doubleclick" → 展开对话窗并进入该会话
"universe:planet:spawned" → 切换对话窗到新生成的会话
"app:ready" → 初始化

// VOX 发出的事件
"voice:recording:start" → 宇宙系统：主星球脉冲加速
"voice:recording:end" → 宇宙系统：主星球恢复常态
"voice:message:send" → 后端：发送消息
"voice:reply:complete" → 宇宙系统：对应星球闪烁
"voice:session:create" → 后端：创建会话 + 宇宙系统：生长动画
"voice:session:switch" → 宇宙系统：相机飞行
```

## 八、给 Crow5 的开发顺序

1. **Day 1-2**：对话窗容器（悬浮、拖动、最小化、调整大小）
2. **Day 3-4**：消息列表 + 消息气泡 + 虚拟滚动
3. **Day 5-6**：录音功能（麦克风+波形+时长）
4. **Day 7-8**：STT 集成（Web Speech API 先行，Whisper 后续）
5. **Day 9-10**：对话流程（发送→思考中→打字机→TTS）
6. **Day 11-12**：事件集成（与宇宙系统通信）
7. **Day 13-14**：打磨（动画、缓存、错误处理）

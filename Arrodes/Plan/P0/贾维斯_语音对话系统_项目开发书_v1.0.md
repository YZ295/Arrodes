# 《贾维斯 · 语音对话系统》项目开发书

> 版本：v1.0  
> 日期：2026-07-23  
> 项目代号：Jarvis-Voice  
> 定位：贾维斯项目的语音交互层，支持实时语音对话 + 意图识别 + 记忆反馈

---

## 一、项目概述

### 1.1 定位
语音对话系统是贾维斯的前端交互层之一，负责：
- **语音输入**：采集用户语音 → 转文字（STT）
- **对话处理**：发送文字给 Hermes/LLM → 获取回复
- **语音输出**：将 AI 回复转为语音播放（TTS）
- **意图识别**：识别"新建会话"等系统指令
- **记忆反馈**：实时提示"记忆已保存"

### 1.2 与宇宙系统的关系

```
┌─────────────────────────────────────────────────────────────┐
│                    贾维斯 · 会话星球宇宙                      │
│                                                             │
│  ┌─────────────────┐        ┌─────────────────────────────┐│
│  │   宇宙可视化层    │◄──────►│      语音对话系统            ││
│  │  · 3D 星球渲染   │        │  · 语音输入/输出            ││
│  │  · 引力轨道      │        │  · 对话消息管理              ││
│  │  · 生长动画      │        │  · 意图识别                  ││
│  └─────────────────┘        │  · 记忆反馈                  ││
│                               └─────────────────────────────┘│
│                    ↑ REST API / WebSocket                   │
│  ┌─────────────────────────────────────────────────────────┐│
│  │              后端：Hermes 记忆层 + LLM                  ││
│  │  · 会话存储  · 语义检索  · 知识图谱  · 语音模型           ││
│  └─────────────────────────────────────────────────────────┘│
└─────────────────────────────────────────────────────────────┘
```

**语音系统不负责**：3D 渲染、星球生成动画、引力计算  
**语音系统负责**：音频采集/播放、消息管理、意图识别、与宇宙系统的状态同步

## 三、非功能需求（NFR）

### 3.1 性能要求
- 首屏加载时间 ≤ 3s（不含模型）
- 模型加载时间 ≤ 10s（Whisper tiny）
- 录音到转录完成 ≤ 5s（10s 语音）
- 消息发送到首字显示 ≤ 2s
- 语音播放延迟 ≤ 1s（TTS 开始）
- UI 交互响应 ≤ 100ms

### 3.2 兼容性
- Chrome ≥ 90, Firefox ≥ 88, Safari ≥ 14, Edge ≥ 90
- 移动端 Safari iOS ≥ 14
- Web Audio API 支持必需

### 3.3 安全
- 语音数据优先本地处理
- 上传云端时 HTTPS 加密
- 敏感内容（密码等）自动过滤不上传

### 4.3 状态设计

```typescript
// 语音系统全局状态
interface VoiceState {
  // 录音状态
  recording: {
    isRecording: boolean;
    duration: number;        // 已录音时长（秒）
    volume: number;         // 当前音量 0~1
    audioBlob: Blob | null; // 录音数据
  };

  // 转录状态
  transcription: {
    isTranscribing: boolean;
    text: string;
    confidence: number;
    isEditing: boolean;    // 用户是否正在编辑
  };

  // 对话状态
  chat: {
    sessionId: string;
    messages: Message[];
    isLoading: boolean;       // AI 思考中
    isTyping: boolean;      // 打字机效果进行中
  };

  // TTS 状态
  tts: {
    isPlaying: boolean;
    isPaused: boolean;
    currentText: string;
    progress: number;       // 播放进度 0~1
    speed: number;          // 语速 0.5~2.0
    volume: number;         // 音量 0~1
    enabled: boolean;       // 是否自动播放
  };

  // 意图识别
  intent: {
    lastIntent: Intent | null;
    confidence: number;
  };

  // 记忆反馈
  memory: {
    recentMemories: MemoryNode[];
    showToast: boolean;
  };

  // 设置
  settings: VoiceSettings;
}

interface Message {
  id: string;
  role: 'user' | 'assistant';
  content: string;
  timestamp: Date;
  isVoice: boolean;         // 是否语音输入
  audioUrl?: string;        // 语音消息 URL
  memories?: MemoryNode[]; // 关联的记忆节点
}

interface Intent {
  type: 'new_session' | 'switch_session' | 'delete_session' | 
        'rename_session' | 'search_memory' | 'summarize' | 
        'clear_context' | 'mute' | 'help' | 'none';
  params: Record<string, string>;
  confidence: number;
}

interface VoiceSettings {
  voiceType: 'male' | 'female' | 'custom';
  speechRate: number;       // 0.5 ~ 2.0
  micSensitivity: number;   // 0 ~ 1
  autoPlayTTS: boolean;
  autoStopRecording: boolean;
  typingSpeed: number;      // ms/字
  notifications: boolean;
}
```

// 语音系统 → 宇宙系统 事件
interface VoiceToUniverseEvents {
  // 新建会话成功

    sessionId: string;
    title: string;

  'session:switched': {

    sessionId: string;
  };

  // 记忆保存
  'memory:saved': {

  };

  };

  // 星球分裂动画完成
  'planet:spawned': {
    sessionId: string;
  };
}

## 七、风险与应对

| 风险 | 可能性 | 影响 | 应对 |
|------|--------|------|------|
| Whisper WASM 模型过大（>100MB） | 中 | 高 | 使用 tiny 模型（~40MB）；首次懒加载 |
| 浏览器不支持 Web Audio API | 低 | 高 | 检测后提示换浏览器 |
| 中文转录准确率低 | 中 | 高 | 云端 fallback；用户可编辑 |
| TTS 中文语音质量差 | 中 | 中 | 支持 ElevenLabs 可选 |
| 意图识别误触发 | 中 | 中 | 置信度阈值；高影响操作需确认 |
| 录音权限被拒绝 | 高 | 高 | 友好引导；文字输入备选 |

### 8.2 后端 API 契约
```
// 创建会话
POST /api/v1/sessions
Body: { title, topic, parentId? }
Response: { id, title, topic, createdAt }

// 发送消息
POST /api/v1/sessions/:id/messages
Body: { content, isVoice? }
Response: { 
  reply: string,
  memories: [{ id, content, type }],
  audioUrl?: string  // 后端 TTS 返回
}

// 或 WebSocket
WS /v1/chat
→ send: { sessionId, content }
← receive: { type: 'chunk'|'complete'|'memory', data }

# 阿罗德斯 · 子系统文档 SS-OPT
# 性能优化系统（Performance & Optimization System）

> 版本：v1.0  
> 代号：OPT  
> 优先级：P2  
> 负责人：Crow5（全栈方向）

---

## 一、模块定位

性能优化系统确保阿罗德斯在**各种设备上都能流畅运行**。从高端台式机到普通笔记本，从 10 个星球到 500 个星球，体验不打折。

---

## 二、功能需求

### 2.1 渲染优化

| 编号 | 需求 | 方案 |
|------|------|------|
| OPT-001 | 视锥剔除（Frustum Culling） | 视口外不渲染 |
| OPT-002 | LOD（细节层次） | 远距离低模 |
| OPT-003 | InstancedMesh（批量渲染） | 相同几何体合并 |
| OPT-004 | 对象池（几何体复用） | 删除的星球回收 |
| OPT-005 | 纹理压缩 | KTX2 / Basis |
| OPT-006 | 后处理精度控制 | 低性能降低 Bloom 采样 |

### 2.2 计算优化

| 编号 | 需求 | 方案 |
|------|------|------|
| OPT-101 | 引力计算在 Web Worker | 不阻塞主线程 |
| OPT-102 | 节流/防抖（交互事件） | 16ms 节流 |
| OPT-103 | 懒加载（按需加载模型） | 首次录音时加载 Whisper |
| OPT-104 | 代码分割（按路由） | 减少首屏体积 |
| OPT-105 | Tree Shaking | 移除无用代码 |

### 2.3 内存优化

| 编号 | 需求 | 方案 |
|------|------|------|
| OPT-201 | 纹理释放 | 不再使用的纹理及时 dispose |
| OPT-202 | 几何体释放 | 对象池管理 |
| OPT-203 | 消息历史分页加载 | 不一次性加载所有消息 |
| OPT-204 | 内存监控面板 | 调试模式显示 |

### 2.4 网络优化

| 编号 | 需求 | 方案 |
|------|------|------|
| OPT-301 | 消息压缩（gzip/brotli） | 服务端启用 |
| OPT-302 | 图片/音频 CDN | 静态资源加速 |
| OPT-303 | 请求合并 | 批量接口 |
| OPT-304 | 离线缓存（Service Worker） | PWA 支持 |

### 2.5 性能监控

| 编号 | 需求 | 验收标准 |
|------|------|---------|
| OPT-401 | FPS 显示（调试模式） | 实时帧率 |
| OPT-402 | 内存占用显示 | 堆内存大小 |
| OPT-403 | 星球数量显示 | 当前渲染数 |
| OPT-404 | 网络请求耗时 | 接口延迟 |
| OPT-405 | 性能报告导出 | JSON 格式 |

### 2.6 离线模式

| 编号 | 需求 | 方案 |
|------|------|------|
| OPT-501 | 网络状态检测 | Navigator.onLine |
| OPT-502 | 离线提示 | 顶部横幅 |
| OPT-503 | 本地 STT（Whisper WASM） | 已加载时可用 |
| OPT-504 | 本地 TTS（Web Speech） | 始终可用 |
| OPT-505 | 消息本地缓存 | IndexedDB |
| OPT-506 | 联网后自动同步 | 后台同步 |

## 三、性能基准

| 场景 | 目标 |
|------|------|
| 首屏加载 | ≤ 5s（含 3D 引擎） |
| 10 个星球 | ≥ 60fps |
| 50 个星球 | ≥ 60fps |
| 100 个星球 | ≥ 45fps |
| 500 个星球 | ≥ 30fps |
| 内存占用 | ≤ 500MB（100 星球） |
| 消息发送延迟 | ≤ 2s（首字） |
| TTS 开始延迟 | ≤ 1s |

---

## 四、验收清单

- [ ] 100 星球时帧率 ≥ 45fps
- [ ] 内存无泄漏（长时间运行稳定）
- [ ] 离线时基本功能可用
- [ ] 性能面板显示正确
- [ ] 低性能模式帧率 ≥ 60fps

---

## 五、开发顺序（持续优化）

1. **Week 1**：视锥剔除 + LOD + 对象池
2. **Week 2**：Web Worker + 节流防抖 + 代码分割
3. **Week 3**：内存优化 + 网络优化
4. **Week 4**：离线模式 + PWA
5. **持续**：性能监控 + 调参

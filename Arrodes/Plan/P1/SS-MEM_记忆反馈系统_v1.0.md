# 阿罗德斯 · 子系统文档 SS-MEM
# 记忆反馈系统（Memory Feedback System）

> 版本：v1.0  
> 代号：MEM  
> 优先级：P1  
> 负责人：Crow5（前端 UI 方向）
> 依赖：SS-VOX（语音对话系统）+ SS-SRV（后端服务）

---

## 一、模块定位

记忆反馈系统让用户**感知到阿罗德斯在记住**。每次对话中，当 AI 提取到新的事实、偏好、事件时，系统以优雅的方式告知用户——不是弹窗打扰，而是如星光般自然闪烁。

**不负责**：记忆存储逻辑（Hermes 负责）、记忆检索  
**负责**：记忆提示 UI、记忆展示、记忆编辑

---

## 二、核心概念

```
用户："我喜欢喝冰美式，不加糖。"

阿罗德斯："在下记下了，大人偏好清冽之苦。"

[💾 已记住：用户喜欢喝冰美式不加糖]
    │
    ▼
┌─────────────────────────────┐
│  顶部轻提示，2s 后淡出        │
│  同时对应星球微微闪烁         │
└─────────────────────────────┘

用户点击提示 → 展开记忆详情面板
```

## 三、功能需求

### 3.1 实时记忆提示

| 编号 | 需求 | 验收标准 |
|------|------|---------|
| MEM-001 | 收到后端 "memory" 事件时显示提示 | 即时 |
| MEM-002 | 提示样式：💾 图标 + "已记住："+ 摘要 | 一行显示 |
| MEM-003 | 提示位置：对话窗顶部居中 | 不遮挡内容 |
| MEM-004 | 提示 2s 后自动淡出 | 淡出动画 0.5s |
| MEM-005 | 多条记忆连续时合并提示 | "已记住 3 条新内容" |
| MEM-006 | 提示可点击展开详情 | 点击后展开面板 |
| MEM-007 | 提示出现时对应星球闪烁 | 视觉关联 |

### 3.2 记忆详情面板

| 编号 | 需求 | 验收标准 |
|------|------|---------|
| MEM-101 | 从提示点击展开，或从会话面板进入 | 两种入口 |
| MEM-102 | 显示记忆完整内容 | 原始文本 |
| MEM-103 | 显示记忆类型（事实/偏好/事件/任务） | 图标区分 |
| MEM-104 | 显示记忆创建时间 | 相对时间（"3 分钟前"）|
| MEM-105 | 支持编辑记忆内容 | 点击编辑 |
| MEM-106 | 支持删除记忆 | 二次确认 |
| MEM-107 | 支持"这不对"反馈 | 反馈给后端 |
| MEM-108 | 面板外点击/ESC 关闭 | 动画关闭 |

### 3.3 会话面板中的记忆展示

| 编号 | 需求 | 验收标准 |
|------|------|---------|
| MEM-201 | 会话详情面板显示"关键记忆"区 | 最多 5 条 |
| MEM-202 | 记忆按类型分组 | 事实/偏好/事件/任务 |
| MEM-203 | 记忆可展开/折叠 | 默认折叠 |
| MEM-204 | 记忆支持编辑和删除 | 同 MEM-105/106 |
| MEM-205 | 显示记忆来源（哪条消息提取） | 可跳转 |

### 3.4 记忆与星球的视觉关联

| 编号 | 需求 | 验收标准 |
|------|------|---------|
| MEM-301 | 记忆保存时，对应星球闪烁 | 1s 内闪烁 2 次 |
| MEM-302 | 星球大小随记忆数量微调 | 每 5 条记忆 +0.1 半径 |
| MEM-303 | 记忆多的星球发光更强 | 视觉反馈 |

## 四、接口（与后端）

```typescript
// 通过 WebSocket 接收
{
  type: "memory";
  data: {
    memories: [{
      id: string;
      content: string;
      type: "fact" | "preference" | "event" | "task";
      sessionId: string;
      createdAt: string;
    }]
  }
}

// 编辑记忆
PATCH /api/v1/memories/:id
Body: { content: string }

// 删除记忆
DELETE /api/v1/memories/:id

// 反馈记忆错误
POST /api/v1/memories/:id/feedback
Body: { reason: string }
```

## 五、事件

```typescript
// MEM 监听
"voice:reply:complete" → 检查 memories 字段，显示提示
"universe:planet:click" → 加载该会话的记忆

// MEM 发出
"mem:memory:saved" → 宇宙系统：星球闪烁
```
